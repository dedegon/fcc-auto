# fcc-auto (claude-auto)

Команда `claude-auto` запускает FCC (Free Claude Code), проверяет бесплатные модели провайдеров и открывает Claude Code. В `/model` попадают только модели, которые реально ответили и поддерживают инструменты.

## Зачем

- В FCC сотни моделей, часть из них не работает или закрыта для аккаунта. Вручную их перебирать долго.
- Claude Code показывает в `/model` всё подряд. `claude-auto` оставляет только проверенные.
- Полный список FCC по-прежнему доступен через `fcc-claude`.

## Требования

- Windows 10/11, PowerShell
- Python не нужен отдельно: установщик ставит uv, а uv ставит нужный Python
- Claude Code (`claude` в PATH)
- Хотя бы один ключ провайдера: OpenRouter, Groq или NVIDIA NIM

## Установка

Клонируйте репозиторий в любую папку и запустите установщик:

    git clone https://github.com/dedegon/fcc-auto.git
    cd fcc-auto
    .\install.ps1

Установщик по шагам:
1. Ставит uv, если его нет.
2. Ставит FCC официальным установщиком, если `fcc-server` не найден.
3. Ставит `claude-auto` через `uv tool install`.
4. Проверяет `claude-auto --help`. Если проверка падает, `claude-auto` удаляется, FCC и Claude Code остаются.

Удалить только `claude-auto`:

    .\install.ps1 -Uninstall

Папку с репозиторием после установки можно не хранить: пакет копируется в папку инструментов uv.

## Подключение провайдеров

Сканер проверяет только провайдеров, для которых есть ключ:

| Провайдер  | Переменная окружения | Где взять ключ |
|------------|----------------------|----------------|
| OpenRouter | `OPENROUTER_API_KEY` | https://openrouter.ai/keys |
| Groq       | `GROQ_API_KEY`       | https://console.groq.com/keys |
| NVIDIA NIM | `NVIDIA_NIM_API_KEY` | https://build.nvidia.com/settings/api-keys |

Ключ добавляется в Admin UI FCC (`http://127.0.0.1:20128/admin` → Providers → Configure → Save → Apply) или переменной окружения. Если ни один провайдер не подключён, `claude-auto` выводит инструкцию и завершается с кодом 2. Ждать ввода он не будет: настройте ключ и запустите команду снова.

## Использование

    cd D:\проект
    claude-auto

Команда запускается из текущей папки, Claude Code открывается там же.

Порядок работы при обычном запуске:
1. Проверяется, какие провайдеры подключены.
2. Если `fcc-server` не запущен, он стартует сам и ждётся готовность.
3. Модели подключённых провайдеров проверяются параллельно: запрос похож на запрос Claude Code (длинный контекст и вызов инструмента).
4. Экран очищается, открывается Claude Code. В `/model` только проверенные модели с пометкой «From gateway».

## Флаги

| Флаг | Что делает |
|------|------------|
| `--offline`, `--offs` | Без сканирования: берутся проверенные модели из кэша |
| `--ping MS`, `--timeout MS` | Сколько ждать ответа одной модели (по умолчанию 15000 мс) |
| `--max-wait SEC` | Общий предел сканирования (по умолчанию 120 с) |
| `--workers N` | Параллельных проверок всего (по умолчанию 24) |
| `--list` | Показать проверенные модели из кэша и выйти |
| `--skip MODEL` | Исключить модель, можно несколько раз |
| `-h`, `--help` | Справка |
| `-- ...` | Всё после `--` передаётся в Claude Code, например `claude-auto -- -p "текст"` |

Примеры:

    claude-auto --ping 3000
    claude-auto --max-wait 60 --workers 30
    claude-auto --offs
    claude-auto --skip groq/openai/gpt-oss-20b

Справка выводится на русском или английском по языку Windows. Принудительно: `CLAUDE_AUTO_LANG=en` или `CLAUDE_AUTO_LANG=ru`.

## Выбор модели

- Если вы выбрали модель через `/model`, она сохраняется в `~/.claude/settings.json` и используется при следующих запусках.
- Если такой записи нет, используется первая проверенная модель.
- Модели в `/model` показываются под именами вида `claude-fcc-<провайдер>-<модель>`. Это нужно, потому что Claude Code отбрасывает модели, чьи ID не начинаются с `claude` или `anthropic`. При отправке запроса фильтр подменяет имя обратно на настоящий ID FCC.

## Настройки

Все значения по умолчанию лежат в `scanner_config.py`:
- `PORT`: порт FCC (8082)
- `PADDING_CHARS`: размер проверочного контекста
- `MIN_TPM`: минимальный лимит токенов в минуту
- `OK_TTL_HOURS`, `FAIL_TTL_MINUTES`: сколько результат считается свежим
- `CACHE_VERSION`: при смене логики увеличьте число, и кэш пересоберётся
- `PROVIDERS`: провайдеры, их адреса и параллельность
- `EXCLUDE`: слова в названиях моделей, которые не проверяются (озвучка, картинки, эмбеддинги и т. п.)

## Файлы

- Кэш результатов: `%LOCALAPPDATA%\claude-auto\cache.json`
- Список для `/model`: `%LOCALAPPDATA%\claude-auto\claude-settings.json`
- Журнал фильтра: `%LOCALAPPDATA%\claude-auto\filter.log`
- Ключи: `~\.fcc\.env` или переменные окружения. В репозиторий они не попадают.

## Диагностика

- Список проверенных моделей: `claude-auto --list`
- Журнал фильтра (запросы `/v1/models`, подмена моделей): `Get-Content "$env:LOCALAPPDATA\claude-auto\filter.log" -Tail 20`
- Состояние FCC: `fcc-doctor`

## Известные ограничения

- Предупреждение `Model "claude-fcc-..." isn't recognized` выводит Claude Code для любой модели, которой нет в его списке. Оно безвредно.
- Лимиты провайдеров: OpenRouter ограничивает бесплатные модели в день, Groq ограничивает токены в минуту (крупные модели отсеиваются как `too_big`).
- Модели NVIDIA с ошибкой 404 «Function not found» не развёрнуты на вашем аккаунте.
- Если выбранная модель перестала работать, выберите другую через `/model`. Сканер не меняет ваш выбор сам.

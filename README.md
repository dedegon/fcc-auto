# fcc-auto (claude-auto)

`claude-auto` запускает FCC (Free Claude Code), проверяет бесплатные модели подключённых провайдеров и открывает Claude Code. В `/model` попадают только модели, которые ответили и поддерживают инструменты.

## Зачем

- В FCC сотни моделей, часть из них не работает или закрыта для вашего аккаунта. Перебирать их вручную долго.
- Claude Code показывает в `/model` всё подряд. `claude-auto` оставляет только проверенные.
- Полный список FCC по-прежнему доступен через `fcc-claude`.

## Требования

- Windows 10/11, PowerShell
- Python отдельно ставить не нужно: установщик ставит uv, а uv ставит нужный Python
- Claude Code (`claude` в PATH)
- Хотя бы один подключённый провайдер FCC

## Установка

Из любой папки:

    git clone https://github.com/dedegon/fcc-auto.git
    cd fcc-auto
    .\install.ps1

Установщик ставит uv (если его нет), FCC официальным установщиком (если `fcc-server` не найден), затем `claude-auto`, и проверяет `claude-auto --help`. Если проверка падает, `claude-auto` откатывается. FCC и Claude Code остаются.

Путь установки записывается в `%LOCALAPPDATA%\claude-auto\install.json`. Если папку перенесли, запустите установщик из новой папки: манифест обновится.

## Удаление

    .\install.ps1 -Uninstall          # спросит подтверждение
    .\install.ps1 -Uninstall -Yes     # без вопроса

Удаляется: команда `claude-auto`, данные и кэш в `%LOCALAPPDATA%\claude-auto`, папка проекта вместе с `.git`. Не затрагиваются FCC, Claude Code и `~\.fcc`.

Удаление работает из любой папки: установщик удаляет папку, в которой лежит сам. Если манифест указывает на другой путь, установщик предупредит об этом.
## Подключение провайдеров

При каждом запуске `claude-auto` спрашивает у FCC через его Admin API, какие провайдеры подключены и сколько у них моделей. Источник правды - сам FCC: подключение через Admin UI учитывается сразу, `.env` для определения не нужен. Список моделей берётся заново при каждом запуске, поэтому новые и пропавшие модели подхватываются автоматически.

Подключить провайдера можно в Admin UI: `http://127.0.0.1:20128/admin` → Providers → Configure → вставить ключ → Save → Apply.

Для прямой проверки моделей сканеру нужен ключ провайдера в переменной окружения или в `~/.fcc/.env`:

| Провайдер  | Переменная окружения | Где взять ключ |
|------------|----------------------|----------------|
| OpenRouter | `OPENROUTER_API_KEY` | https://openrouter.ai/keys |
| Groq       | `GROQ_API_KEY`       | https://console.groq.com/keys |
| NVIDIA NIM | `NVIDIA_NIM_API_KEY` | https://build.nvidia.com/settings/api-keys |

Перед сканированием выводится отчёт:
- `[OK]` подключён и ключ есть, модели сканируются;
- `[KEY]` подключён в FCC, но ключа для прямой проверки нет;
- `[ERR]` FCC не смог получить модели, проверьте ключ;
- `[--]` не подключён, рядом ссылка на ключ.

Если ни один провайдер не готов, `claude-auto` выводит инструкцию и завершается с кодом 2. Ждать ввода он не будет: настройте провайдера и запустите команду снова.

## Использование

    cd D:\проект
    claude-auto

Команда запускается из текущей папки, Claude Code открывается там же.

Порядок при обычном запуске:
1. Проверяются подключённые провайдеры и выводится отчёт.
2. Если `fcc-server` не запущен, он стартует сам, и программа ждёт его готовности.
3. Модели готовых провайдеров проверяются параллельно. Запрос похож на запрос Claude Code: длинный контекст и вызов инструмента.
4. Экран очищается, открывается Claude Code. В `/model` только проверенные модели с пометкой «From gateway».

## Флаги

| Флаг | Что делает |
|------|------------|
| `--offline`, `--offs` | Без сканирования: проверенные модели берутся из кэша |
| `--ping MS`, `--timeout MS` | Сколько ждать ответа одной модели (по умолчанию 15000 мс) |
| `--max-wait SEC` | Общий предел сканирования (по умолчанию 120 с) |
| `--workers N` | Параллельных проверок всего (по умолчанию 24) |
| `--list` | Показать проверенные модели из кэша и выйти |
| `--skip MODEL` | Исключить модель, можно указать несколько раз |
| `-h`, `--help` | Справка |
| `-- ...` | Всё после `--` передаётся в Claude Code, например `claude-auto -- -p "текст"` |

Примеры:

    claude-auto --ping 3000
    claude-auto --max-wait 60 --workers 30
    claude-auto --offs
    claude-auto --skip groq/openai/gpt-oss-20b

Справка выводится на русском или английском по языку Windows. Принудительно: `CLAUDE_AUTO_LANG=en` или `CLAUDE_AUTO_LANG=ru`.

## Выбор модели

- Модель, выбранная через `/model`, сохраняется в `~/.claude/settings.json` и используется при следующих запусках.
- Если такой записи нет, используется первая проверенная модель.
- В `/model` модели показываются под именами вида `claude-fcc-<провайдер>-<модель>`. Claude Code отбрасывает модели, чьи ID не начинаются с `claude` или `anthropic`, поэтому имена переименованы. При отправке запроса фильтр подменяет имя обратно на настоящий ID FCC.

## Настройки

Значения по умолчанию лежат в `scanner_config.py`:
- `PORT`: порт FCC (8082)
- `PADDING_CHARS`: размер проверочного контекста
- `MIN_TPM`: минимальный лимит токенов в минуту
- `OK_TTL_HOURS`, `FAIL_TTL_MINUTES`: сколько результат считается свежим
- `CACHE_VERSION`: при смене логики увеличьте число, и кэш пересоберётся
- `PROVIDERS`: провайдеры, их адреса, ключи и параллельность
- `EXCLUDE`: слова в названиях моделей, которые не проверяются (озвучка, картинки, эмбеддинги и т. п.)

## Файлы

- Кэш результатов: `%LOCALAPPDATA%\claude-auto\cache.json`
- Список для `/model`: `%LOCALAPPDATA%\claude-auto\claude-settings.json`
- Журнал фильтра: `%LOCALAPPDATA%\claude-auto\filter.log`
- Ключи: `~\.fcc\.env` или переменные окружения. В репозиторий они не попадают.

## Диагностика

- Проверенные модели: `claude-auto --list`
- Журнал фильтра: `Get-Content "$env:LOCALAPPDATA\claude-auto\filter.log" -Tail 20`
- Состояние FCC: `fcc-doctor`

## Известные ограничения

- Предупреждение `Model "claude-fcc-..." isn't recognized` выводит Claude Code для любой модели, которой нет в его списке. Оно безвредно.
- Лимиты провайдеров: OpenRouter ограничивает бесплатные модели в день, Groq ограничивает токены в минуту. Крупные модели отсеиваются как `too_big`.
- Модели NVIDIA с ошибкой 404 «Function not found» не развёрнуты на вашем аккаунте.
- Если выбранная модель перестала работать, выберите другую через `/model`. Сканер не меняет ваш выбор сам.
